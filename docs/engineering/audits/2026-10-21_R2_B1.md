## 1. Mapa de componentes y dependencias

- `scripts/r2/grid_model.gd` (`GridModel : RefCounted`) mantiene como fuente única las 144 alturas/superficies del baseline, con coordenadas `Vector2i(x,z)`, validación de límites y sentinel `-1`. No depende de `Node`, SceneTree ni recursos gráficos.
- `scripts/isometric_art_test.gd` consulta el modelo para terreno, resaltado y HUD; contiene la conversión local lógica→`Vector3`. Mantiene `selected_coordinate` y `actor_coordinate` separados. El actor y la sombra son proyecciones visuales de `actor_coordinate`.
- La escena conserva cámara, construcción de mallas/colliders, props, input y HUD en el script original. Sigue siendo un script de prueba con responsabilidades mixtas; su extracción se reserva para B2/B3 y no se recomienda una reescritura masiva en B1.
- El picking entrega un collider a `select_grid_collider()`. Esta función valida tipo, grupo, existencia/tipo de `tile_x` y `tile_z`, límites y congruencia de `height_level` con `GridModel` antes de actualizar selección.
- No se añadieron autoloads ni señales. Las llamadas de input validan estado en el ensamblaje; `GridModel` no interpreta cámara, texturas ni sprites. No se observan dependencias circulares nuevas.

## 2. Robustez y seguridad

- **Única fuente de verdad de altura/superficie:** `GridModel`. El render y el HUD consultan el modelo; las matrices duplicadas del script fueron eliminadas.
- `select_cell()` y `move_actor_to()` validan coordenadas antes de mutar. Agua y destinos fuera de límites se rechazan sin cambios en `actor_coordinate`, sprite o sombra. Las consultas inválidas del modelo continúan devolviendo sentinel y no se indexan como datos válidos.
- La actualización visual del actor se calcula desde `actor_coordinate`; seleccionar otra celda no mueve la unidad. `apply_actor_texture()` valida recurso, ancho/alto positivo, escala finita y coordenada antes de mutar textura, escala, actor o sombra.
- **B1-ANCHOR-01 — RESUELTO:** el test-first en escena recién instanciada falló antes del fix. Godot importó el proxy como **512×550**, con `pixel_size=0.00325` y `centered=true`; semialtura real `0.89375`. El centro inicial medido fue Y=`1.31375003` sobre superficie Y=`0.42`. El antiguo offset fijo `0.825` habría dejado los pies `0.06875` unidades bajo el terreno al mover antes de cambiar textura. El movimiento ahora usa `texture.get_height() * pixel_size / 2`; las variantes de escala normalizada calculan la semialtura después de validar dimensiones.
- `ImageTexture.new()` de dimensiones no positivas se rechaza sin cambiar textura, escala, coordenada, sprite o sombra. La regresión usa el SVG versionado y no depende de la PNG privada.
- **MINOR pendiente B2:** un `StaticBody3D` fabricado podría añadirse al grupo `grid_tile` y llevar metadatos plausibles. Las pruebas rechazan collider ajeno sin metadatos, fuera de rango o con altura incongruente; la pertenencia a una futura `GridView` debe verificarse cuando se extraiga esa vista. No se implementa sistema de mods ni amenazas de contenido externo en este checkpoint.
